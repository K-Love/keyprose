What this covers

This policy covers the public website at https://keyprose.com. I run that site as Backstage Interactive, a one-person studio. It does not cover backstageinteractive.com, Wild Thesis, or a copy of this software that someone else hosts.

www.keyprose.com redirects to https://keyprose.com. keyprose.app and www.keyprose.app serve this same website. The canonical address for this page is https://keyprose.com/privacy.

Who this is

“I” means Kevin Love. Backstage Interactive is the name of this one-person studio. It is not a team, and this page does not name a separate company. KeyProse does not publish a street address, a phone number, or an email address.

How to reach me

KeyProse does not have its own contact form. For a privacy question, or to ask for a copy or a deletion, use the contact form on the Backstage Interactive homepage (opens in a new tab). In the note, say that it is about KeyProse, and include enough detail for me to recognize the request. That form asks for an email address so I can reply.

This page does not add an email address or a phone number. I do not promise a number of days for a reply.

What you can submit

The site has five tools. What you type is sent to this site so it can draft a reply. There is no account. Each tool can fill the fields with example text. Those examples are not a real client’s listing.

Listing Writer

You can enter an address, bedrooms, bathrooms, size, year built, list price, neighborhood, features, tone, and length. The site receives all of that. Sample copy can mention the neighborhood. A live description is written from the address, size, year, features, and price. The neighborhood field is not added to that live request. The price is included.

CMA Assistant

You can enter a subject address, bedrooms, bathrooms, size, and comparable sales. A comparable sale can include an address, sale price, size, bedrooms, bathrooms, and a sold date. The value, the range, and the price per square foot are calculated from the prices and sizes you enter. The written summary is sample text, or text from the model when a live draft succeeds. The PDF comes back with that reply and says it is not an appraisal. The public site does not keep the file.

Social Generator

You can enter a property id, an address, bedrooms, bathrooms, size, price, a highlight, a tone, and a platform. The platforms are Instagram, Facebook, Twitter/X, LinkedIn, or all of them. The tool drafts posts. It does not publish them.

Email Campaigns

You can enter a recipient type, a first name, an agent name, a property address, a price, a highlight, and how many emails to draft. The tool drafts the emails. It does not send them.

Outreach Engine

You can enter a name, an email address, and a type for each contact, choose a sequence, and add an optional note. The site receives those so it can show a preview. It does not email the contacts.

The built-in sequences (new listing, price drop, open house, and follow-up) are written on this site. They are not sent to the model. A custom sequence can be sent to the model. That message uses names, contact types, and the note. The email-address field is not added to it. An address you type into a name or the note can still be included.

What the server does with it

The site uses what you submit to build a reply and show it in your browser. The draft stays on that page until you leave or reload. It is not saved as a history of past generations, and it is not written into a database of listings.

There are two kinds of reply:

  • Sample copy, when a live draft is not available, is limited, is too long, or fails. The page says so when it can.
  • A live draft. The text needed to write it is sent to the provider below.

The AI provider

On November 7, 2026, live drafts on the public site were sent to Abacus RouteLLM at routellm.abacus.ai. The public status check shows that host. It does not show which model answered, so this page does not name a model. If the host is changed later, live drafts go to the new host instead.

This site does not tell the provider how long to keep a draft request, and it does not tell the provider whether that request may be used for training. I am not stating those rules here. Abacus publishes its own privacy policy at abacus.ai/privacy-policy (opens in a new tab). That page is theirs. I am not copying it into this policy as a promise about KeyProse.

If a live draft cannot be completed, you get sample copy instead.

What is saved

The listing, the comparable sales, the contact list, and the draft are used to make the reply. They are not stored as a saved history on this site.

When a live draft is attempted, the site keeps a count so it can limit how often live drafts run. It keeps a count for your network each hour, and one count per day for the whole site. The count is not your listing text. The usual limits are 10 live drafts an hour for a network and 200 a day for the site. The host can change those numbers. This page does not set how long the counts are kept.

The CMA file is part of the reply your browser receives. The public site does not save that file for you to fetch later.

Your browser

These pages do not set a cookie, and they do not save a draft in your browser. When you reload or leave, the draft on the screen is gone unless you copied it. Your browser’s own history can still list the page address. This site does not put the draft there.

A copy button uses your browser’s clipboard. This site does not receive another copy from that step.

The pages use the fonts already on your device. They do not request a font file from Google.

Hosting and logs

Netlify hosts the public site. When your browser requests a page or asks for a draft, the host receives the ordinary connection data needed to deliver it, such as an IP address, the page address, the time, and the browser’s user-agent string. This site does not set how long the host keeps those logs. Netlify’s privacy policy is the host’s own description: netlify.com/privacy (opens in a new tab).

The public address uses HTTPS. This page does not promise encryption at rest.

Cookies, analytics, and forms

The pages do not include an analytics script, an advertising pixel, or a cookie banner. They do not set a cookie. I am not describing optional products that can be switched on in the hosting account. Those switches are not part of these pages.

The tool fields are not stored as a contact-form submission. They are used to build the reply described above.

This site does not sell what you submit, and it does not send it to an advertising network. A live draft does send the text needed to write it to the provider named above, so that provider receives it.

Accounts and payment

There is no sign-in and no payment. The homepage says authentication, billing, and a production database are not included. Using a tool does not create an account and does not charge a card.

  • Netlify’s privacy policy (opens in a new tab) is the host’s own page.

  • Instagram, Facebook, X, LinkedIn, an email program, or an MLS, if you copy a draft and publish or send it yourself. This site does not post or send it for you.

Wild Thesis is a separate website with its own privacy policy. This page does not govern it.

How long information stays

A draft on the screen lasts until you reload or leave. This site does not keep a history of it.

The live-use counts stay until they are removed. This site does not set a deletion date for them.

This site does not state how long Netlify keeps logs, or how long the AI provider keeps a request. I am not stating a number of days for either one.

Asking for a copy or deletion

Use the contact form on the studio homepage. Say that you want a copy or a deletion, and that the request is about KeyProse. Include the approximate time and which tool you used.

The listing text is not stored with the live-use counts. A request about a draft will usually have no saved draft for me to delete from KeyProse. I will say so when that is the case. I cannot describe from this site what copy Netlify or Abacus keeps.

Children

This site is written for adults doing real estate work. It is not directed at children. Do not submit a child’s personal information. The tools do not ask for a child’s age.

Changes

If I change this policy, I will update this page and the effective date at the top. This version is effective November 7, 2026. This site has no mailing list for policy notices.
